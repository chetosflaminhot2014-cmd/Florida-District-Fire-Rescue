# Florida City Models — Asset Record

- Models: Kenney City Kit (Suburban), selected GLB models building-type-a through building-type-h.
- Texture: Kenney colormap.png.
- License: CC0 1.0 Universal, as stated by the original Kenney asset page and the included License.txt.
- Original asset page: https://kenney.nl/assets/city-kit-suburban
- Mirror used by CI for reproducible downloads: https://github.com/petroulacl/fps-buildings-env-kit
- Godot format: glTF Binary (.glb), loaded by Godot 4 without an additional importer.
- Size: the eight GLB files total under 1 MB based on the mirror's published Git object sizes; the shared texture is about 12 KB.
- Visual note: these are optimized, textured, stylized low-poly buildings—not photorealistic scans. The game uses them as real mesh facades rather than generating building-shaped cubes.
